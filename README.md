**Thirst was Reclaimed** is a simple mod that adds a thirst mechanic to the game, but that fits well in modpacks (extend from TWT) by adding diverse features and compatibility with a lot of often-used mods.

This mod aimed to offer better compatibility with vanilla and other mods.

To learn more about this mod, you can visit the [Wiki](https://github.com/mlus-asuka/Thirst-Was-Reclaimed/wiki).
